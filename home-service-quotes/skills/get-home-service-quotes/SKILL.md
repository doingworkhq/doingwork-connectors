# Get home service quotes

## When to use
- Something at home is broken, leaking or worn out, or the user wants something built or installed.
- The user asks for quotes, estimates or "a few local shops" for a home job.
- The user asks whether any quotes came back on a job they already sent.

## When not to use
- A gas smell, sparking, flooding or anything else that is dangerous right now. Tell the user to leave if needed and call 911 or their utility first.
- Commercial jobs or work outside the US.

## Steps
1. Ask the user to describe the job in their own words and add photos if they have them. Ask only what a shop needs to price it.
2. Show the summary and the property address, and confirm them with the user before finding shops.
3. Show the local shops with the reason for each. Remove any the user doesn't want.
4. Show the exact message and shop list. Send only after the user approves.
5. Later, read the quotes in the order they arrived. When the user picks a shop, confirm first: hiring shares their phone and email with that shop and closes the request, and it can't be undone.

Every step that reaches a shop returns a preview and a confirm token first. Never call the second step without the user's clear yes.
